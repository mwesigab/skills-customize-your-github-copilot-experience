
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a playable Hangman game in Python. Practice strings, loops, conditionals, user input, and random selection while tracking a player's progress.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description

Create a word-guessing game that selects a word from a predefined list and lets the player guess letters until they solve the word or run out of attempts.

#### Requirements

Completed program should:

- Randomly select a word from a predefined list at the start of each game.
- Display each letter in the word as a blank, revealing letters when guessed correctly.
- Accept letter guesses and track incorrect guesses and remaining attempts.
- End when the player guesses the word or runs out of attempts.
- Display a clear win or loss message and reveal the word when the player loses.

### 🛠️ Handle Guesses and Game States

#### Description

Make the game respond clearly to guesses and show the player what is happening throughout the round.

#### Requirements

Completed program should:

- Tell the player when a guess is correct or incorrect.
- Ignore or explain guesses that are not a single letter.
- Avoid counting a repeated letter guess as a new incorrect guess.
- Show the current word progress and remaining attempts after each valid guess.
